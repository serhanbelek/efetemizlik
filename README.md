# Efe Temizlik - Profesyonel Temizlik Hizmetleri

Efe Temizlik şirketi için profesyonel, modern ve duyarlı (responsive) web sitesi.

## Özellikler

- 🏠 **Ana Sayfa** - Hero bölümü, istatistikler ve çağrı butonları
- 🧹 **Hizmetler** - 6 farklı temizlik hizmeti kartı
- 📋 **Hakkımızda** - Şirket tanıtımı ve avantajlar
- 💰 **Fiyatlar** - 3 farklı fiyat paketi (Temel, Standart, Premium)
- 📸 **Galeri** - Filtrelenebilir çalışma örnekleri
- ⭐ **Müşteri Yorumları** - Otomatik kayan yorum slider'ı
- ❓ **SSS** - Açılır/kapanır sıkça sorulan sorular
- 📞 **İletişim** - Form doğrulamalı iletişim formu
- 💬 **WhatsApp Butonu** - Hızlı WhatsApp iletişimi
- ⬆️ **Yukarı Çık Butonu** - Sayfa başına hızlı dönüş
- 📱 **Responsive Tasarım** - Mobil, tablet ve masaüstü uyumlu
- 🎨 **Animasyonlar** - Sayaç, kaydırma ve geçiş animasyonları
- 🔍 **SEO** - Meta etiketleri ve Open Graph desteği

## Kullanılan Teknolojiler

- HTML5
- CSS3 (CSS Grid, Flexbox, CSS Variables, Animations)
- Vanilla JavaScript (ES5+)
- Google Fonts (Poppins)

## Kurulum

Herhangi bir build adımı gerekmez. `index.html` dosyasını tarayıcıda açarak siteyi görüntüleyebilirsiniz.

```bash
# Yerel sunucu ile çalıştırmak için (opsiyonel)
npx serve .
```
