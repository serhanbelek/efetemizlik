# Efe Temizlik

Efe Temizlik profesyonel temizlik hizmetleri web sitesidir.

## Özellikler

- Duyarlı (responsive) tasarım — mobil ve masaüstü uyumlu
- Hizmetler, hakkımızda ve iletişim bölümleri
- İletişim formu
- Mobil menü desteği

## Kullanım

`index.html` dosyasını tarayıcıda açarak siteyi görüntüleyebilirsiniz.

## Dosya Yapısı

```
├── index.html       # Ana sayfa
├── css/
│   └── style.css    # Stil dosyası
├── js/
│   └── main.js      # JavaScript işlevleri
└── README.md
```
